
# 标题
一款基于deepseek、可以帮你省钱&赚钱的智能购物领券助手
基于uni-ai开发，在uniCloud实现了以deepseek作为基模、三大电商平台api为工具、具有上下文记忆功能的购物智能体，未采用任何框架，纯手工实现，非常轻量级。
作者前阿里技术专家。

# 简介
本项目是一个集本地生活、电商和Ai购物于一体的综合型购物返利小程序/app. 
1. 本地生活：点奶茶/咖啡、点外卖、电影票等日常所需，在这里都可以领到红包或优惠券
2. 购物优惠券：三大电商平台淘宝、京东和拼多多购物，在这里都可以领优惠券，同时还可以返现金
3. Ai购物助手：自己懒得在各个app之间来回切换，有任何购物问题直接问她，她都可以秒级给你最全网性价比最高的商品
4. 电商开放平台签名：淘宝、京东和拼多多完整的签名生成算法代码，对刚入局电商的小伙伴非常有帮助
